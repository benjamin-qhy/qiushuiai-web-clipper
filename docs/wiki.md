# 秋水 · 网页剪藏

> 将飞书文档、金山文档、任意网页一键保存为 Obsidian Markdown 笔记。

支持平台：Chrome · Firefox

## 核心特性

- **飞书文档剪藏**：支持飞书 docx 与 wiki 页面，完整保留标题层级、代码块、表格、图片
- **金山文档剪藏**：支持 kdocs.cn 文档，自动滚动加载全文后提取
- **通用网页剪藏**：任意网页提取正文、标题、作者、发布时间，转为干净的 Markdown
- **灵活的图片处理**：支持独立模式、共享模式、阿里云云存储三种方式
- **书签管理**：内置书签管理器，支持人工智能自动分类与 Markdown 导出
- **自动生成文档属性**：标题、来源链接、作者、发布时间、创建时间、摘要、标签，一次性写入 frontmatter

## 一、下载与安装

### 下载插件

> 📎 **[点击下载插件 zip 文件]**（附件见本文档底部）

下载后得到一个 `.zip` 压缩包，解压备用。

### Chrome 安装步骤

1. 打开 Chrome，在地址栏输入 `chrome://extensions/`
2. 右上角开启**开发者模式**
3. 点击**加载已解压的扩展程序**
4. 选择解压后的文件夹，完成安装

<!-- 截图②：Chrome 扩展管理页，已开启开发者模式、插件安装成功后的状态 -->
[截图②：Chrome 安装成功后的扩展管理页]

安装成功后，浏览器工具栏会出现插件图标。

### Firefox 安装步骤

1. 打开 Firefox，在地址栏输入 `about:debugging`
2. 点击左侧**此 Firefox**
3. 点击**临时载入附加组件**
4. 选择解压后文件夹内的 `manifest.json` 文件，完成安装

> ⚠️ Firefox 临时安装在重启浏览器后会失效，需重新安装。

## 二、初始配置

首次使用前，需完成以下三步配置。点击浏览器工具栏中的插件图标，然后点击右上角的**设置**按钮进入配置页。

<!-- 截图③：设置页整体截图，展示子目录、图片模式等配置项 -->
[截图③：设置页整体截图]

### 1. 授权 Obsidian 笔记库目录

点击**选择笔记库**，在弹出的文件夹选择框中选择你的 Obsidian vault 根目录。浏览器会请求对该目录的读写权限，点击允许即可。

授权后，插件会记住该路径，后续无需重复操作。

### 2. 设置子目录

可选配置。填写后，所有剪藏的笔记会统一保存到 `{笔记库}/{子目录}/` 下，便于分类管理。

例如填写 `Clippings`，则笔记保存路径为 `vault/Clippings/笔记标题.md`。

不填则直接保存到笔记库根目录。

### 3. 图片存储模式

插件支持三种图片处理方式，可按需选择：

| 模式 | 说明 | 适合场景 |
|------|------|----------|
| **独立模式**（默认） | 每篇笔记的图片保存到专属的 `笔记名.assets/` 目录 | 笔记独立归档，互不干扰 |
| **共享模式** | 所有笔记的图片统一保存到一个共享目录 | 多篇笔记引用同一图片素材 |
| **云存储模式** | 图片上传到阿里云 OSS，笔记中引用完整 URL | 跨设备同步、团队协作 |

云存储模式需额外填写阿里云 OSS 的 Bucket、AccessKey 等配置信息。

## 三、网页剪藏

### 支持来源

| 来源 | 适用页面 |
|------|----------|
| 飞书文档 | `*.feishu.cn/docx/*` 及 `*.feishu.cn/wiki/*` |
| 金山文档 | `*.kdocs.cn/l/*` |
| 通用网页 | 其他所有网页 |

插件会自动识别当前页面类型并选用对应的提取方式，无需手动切换。

### 操作步骤

1. 打开需要剪藏的页面，等待页面完全加载
2. 点击浏览器工具栏中的**秋水剪藏**图标
3. 弹窗中会显示识别到的标题和作者等信息，确认无误后点击**保存到 Obsidian**
4. 保存成功后弹窗会显示文件保存路径

> 💡 飞书和金山文档包含懒加载内容时，插件会自动滚动页面触发加载，完成后再提取，无需手动操作。

### 输出说明

每篇剪藏的笔记包含两部分：

**文档属性（frontmatter）**

```yaml
---
title: 文章标题
source: https://原始链接
author: 作者名
published: 2024-01-01
created: 2024-06-01
description: 文章摘要
tags: []
---
```

**正文内容**

飞书和金山文档完整保留原始结构，包括标题层级、粗体、斜体、代码块、表格、引用块等。图片按所选存储模式处理。

通用网页提取主要正文，自动过滤导航栏、广告、页脚等无关内容。

## 四、书签管理

点击插件图标，切换到**书签**标签页，进入书签管理器。

<!-- 截图⑥：书签管理页整体截图，展示左侧文件夹树 + 右侧书签列表 -->
[截图⑥：书签管理页整体截图]

### 书签树与列表

左侧为书签文件夹树，右侧展示当前文件夹下的书签列表。支持按标题关键词搜索。

### 人工智能自动分类

点击**AI 分类**按钮，插件会调用 AI 分析所有未分类书签的标题和 URL，自动归入合适的文件夹。

<!-- 截图⑦：AI 分类侧边栏展开状态，展示分类结果或处理进度 -->
[截图⑦：AI 自动分类结果]

使用前需在设置页配置 AI 服务信息（支持阿里云通义千问及其他兼容 OpenAI 接口的服务）：

- **API 地址**：服务的接口地址
- **API Key**：访问密钥
- **模型名称**：使用的模型，例如 `qwen-turbo`

### 导出为 Markdown

点击**导出**按钮，可将当前书签树导出为一份结构化的 Markdown 文件，保存到 Obsidian 笔记库中。

## 五、常见问题

**Q：插件安装后看不到图标怎么办？**

Chrome 中点击工具栏右侧的拼图图标，找到「秋水剪藏」，点击固定到工具栏即可。

**Q：点击保存后提示「请先选择笔记库」？**

尚未完成初始配置，请进入设置页点击「选择笔记库」授权目录。

**Q：飞书文档图片保存失败？**

图片需要在飞书登录状态下才能下载。请确保当前浏览器已登录飞书账号，然后重试。

**Q：通用网页剪藏的正文内容不完整或有多余内容？**

通用网页的正文提取依赖页面结构，部分页面结构特殊可能影响提取效果。目前暂不支持手动框选正文区域，可在 Obsidian 中手动修改。

**Q：云存储模式下图片上传失败？**

请检查 OSS 配置中的 Bucket 名称、地域、AccessKey 是否填写正确，以及 Bucket 是否已开启公共读权限。

**Q：Firefox 重启后插件消失了？**

Firefox 临时安装的插件在重启后会失效，这是 Firefox 的限制。需要每次重启后重新安装，或等待后续正式上架 Firefox 附加组件商店。

**Q：AI 分类功能不工作？**

请检查设置页中的 AI 服务配置是否填写完整，尤其是 API Key 和模型名称。可在设置页点击「测试连接」验证配置是否正确。
