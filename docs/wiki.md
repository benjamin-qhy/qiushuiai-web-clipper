# clip publish 使用说明

项目名与扩展显示名称为“clip publish”。

## 安装与初始设置

按 [项目说明](../README.md#本地开发与安装) 构建并加载 Chrome 或 Firefox 产物。首次使用时点击扩展图标，在弹窗选择 Obsidian 笔记库并允许目录读写。设置页可配置保存子目录、图片模式、OSS、Get 笔记、AI 模型与系统提示词。

图片默认保存在每篇笔记的 `.assets/` 目录，也可使用共享目录或阿里云 OSS。云存储须填写相应凭据。

## 剪藏网页

1. 打开飞书 docx/wiki、金山文档或通用网页，等待页面加载。
2. 点击“clip publish”图标，确认提取到的标题、来源与正文。
3. 修改需要保存的元数据，点击保存。Markdown 与本地图片写入授权笔记库，OSS 图片以 URL 引用。

frontmatter 包含标题、来源、作者、发布时间、创建时间、摘要和标签；没有指定标签时默认使用 `clippings`。飞书与金山文档会滚动页面触发懒加载。

## Get 笔记与抖音收藏

设置页填写 Get 笔记的 clientId 和 authToken。弹窗可直接保存当前链接；Get 笔记请求保存链接与可选标签。

在抖音收藏页点击扩展图标进入收藏侧边栏，抓取内容、勾选条目并批量导入 Get 笔记。导入进度保存在本地，刷新后可继续。

## 发布工作台

Chrome 在弹窗或设置页点击“发布工作台”打开 React 发布页面。先启动或连接发布 API，按 [API 说明](../packages/publishing-api/README.md) 登记执行电脑、生成配对码并配对扩展，再登记账号与素材。

平台写操作由 [发布 Skill](../skills/haiqiai-publishing/SKILL.md) 调用 API 触发扩展执行，内容按图文、视频、文章入口提交。最终动作明确选择保持页面、保存草稿或发布；遇到中断先查原任务与原编辑页，按支持的恢复规则继续。

发布页显示连接、账号、任务、原因及作品链接。已提交、已发布、需人工处理与结果未知分别表示不同证据，不能仅凭点击成功判断发布成功。当前验收范围见 [交接](research/2026-10-10-publishing-handoff.md)。Firefox 隐藏发布入口，未注册发布后台。

## 常见问题

- 没有扩展图标：在浏览器扩展菜单中将“clip publish”固定到工具栏。
- 保存笔记失败：核对笔记库授权、文件名、子目录和 OSS 配置，依据错误信息处理。
- Firefox 临时扩展消失：浏览器重启后需重新加载；本地目录选择取决于浏览器对 File System Access API 的支持。
- 发布连接离线：检查所选 API 地址和执行浏览器。新电脑的 localhost 指向新电脑；Git 不同步账号登录、API 密钥或浏览器本地草稿。

旧书签管理和图片卡片创作工作台已移除；历史设计文档不表示这些功能仍可使用。
