# 系统提示词管理设计

## 目标

在设置页“模型配置”区块下方增加“系统提示词管理”。用户可查看已添加的提示词、新增提示词和编辑已有提示词。每条提示词仅包含标题与提示词内容，均为必填项。

## 范围

- 提示词只作为本地可维护的数据列表保存，不接入模型测试、书签 AI 分类或其他 AI 请求。
- 不提供删除功能。
- 不要求标题唯一，按添加顺序展示。

## 数据与持久化

- 新增 `SystemPrompt` 类型，包含稳定 `id`、`title` 和 `content`。
- `Settings` 新增 `systemPrompts: SystemPrompt[]`，默认值为空数组。
- 读取旧设置时，未包含该字段的配置自动得到空数组；保存时随现有设置一并写入浏览器本地存储。
- `useSettings` 的初始值与保存快照均复制提示词数组及其条目，避免编辑界面改变已排队的保存快照。

## 界面与校验

```text
模型配置
────────────────────────
系统提示词管理
├─ 已添加提示词
│  ├─ 标题 / 内容摘要  [编辑]
│  └─ 标题 / 内容摘要  [编辑]
└─ + 新增提示词
   ├─ 标题 *
   ├─ 提示词内容 *
   └─ 保存 / 取消
```

- 使用独立的 `SystemPromptSection.vue`，由设置页在 `ModelConfigSection` 后渲染。
- 新增与编辑共享表单；新增时生成 ID，编辑时保留原 ID 与列表位置。
- 保存前对标题和内容做首尾空白清理；清理后任一字段为空时显示字段错误，不更新列表。
- 列表仅显示内容摘要，编辑时显示完整内容。

## 验证

- 存储测试覆盖默认空列表、旧设置兼容及保存。
- UI 测试覆盖管理区位于模型配置之后、标题与内容输入以及编辑入口。
- 先运行新增测试并确认失败，再实现；完成后运行相关测试、全量 Vitest、`pnpm compile` 与 `pnpm build`。
