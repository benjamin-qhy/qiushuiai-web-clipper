# 内容发布工作台空间优先重设计

## 目标

依据根目录 `design.md` 的 assistant-ui 设计语言重构内容发布工作台，把主要视口交还给原文阅读、Markdown 编辑和卡片预览，移除占据整行的次要控制与重复分页。

## 设计原则

- 页面采用纸张语义：低彩度沙色背景、方正全幅页面、少量发丝线，不使用装饰阴影或层层卡片。
- 印刷内容最多使用 6px 圆角；按钮、字段和菜单等可操作对象使用 8px 以上的控件圆角。
- 界面结构和控件保持单色，只用一个蓝色表达当前选中或活动状态。
- 图标只服务于明确动作，必须保留可访问名称；不以无标签图标替代模型、提示词等业务含义。
- 每个阅读时刻只有一个主对象，各面板将剩余高度用于正文、编辑器或卡片画布。

## 布局

### 全局头部

头部压缩为单行。左侧显示工作台名称，右侧显示保存状态、布局菜单和重置入口。原来的“隐藏原文 / 隐藏创作 / 隐藏成品”整行工具栏迁入布局下拉菜单。

### 宽屏

宽屏保留三栏可拖动布局，默认比例调整为原文 28%、创作 40%、成品 32%。创作区获得最大宽度，各栏内部独立滚动。

### 中屏与窄屏

中屏不再同时挤入两个狭窄面板，改为单一活动面板切换；切换控件放入紧凑的 Button Group。窄屏沿用同样的单面板逻辑，避免重复导航结构。

## 面板

### 原文

标题栏仅保留编号、名称和来源链接。元数据与正文使用排版层级分组，不增加额外卡片边框。

### 创作稿

模型、推理程度、提示词模板整合为紧凑工具栏。编辑/预览使用 Button Group。Markdown 编辑器填满剩余垂直空间，最低高度随视口变化，不再被纵向表单挤压。

### 发布成品

主题选择、封面开关与导出动作合并为紧凑工具栏。卡片预览占据面板主体。删除数字缩略图列表，只保留“上一页 / 当前页与总页数 / 下一页”一套分页；导出当前页和全部页面使用一组相关按钮。

## 组件

- 使用 Dropdown Menu 承载布局显示、主题选择等次要操作。
- 使用 Button Group 组织区域切换、编辑/预览、分页与相关导出动作。
- 菜单是浮动表面，使用圆角和轻微提升；页面与全幅区域保持方正。
- 复用现有 shadcn/Base UI 风格组件，不增加另一套交互实现。

## 验收标准

- 顶部不再有独占整行的区域显示按钮。
- 宽屏三栏中创作区为最宽面板，编辑器拥有明显更大的可用面积。
- 中屏与窄屏一次只显示一个完整面板。
- 成品区只有一套页码导航，不再显示重复数字缩略图。
- 模型、提示词、主题、封面、分页和导出行为保持可用。
- 全量测试、类型检查、Web 构建和扩展构建通过。
- 实际渲染检查宽屏、窄屏以及主要交互状态。
