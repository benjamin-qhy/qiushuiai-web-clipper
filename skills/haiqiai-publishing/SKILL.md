name: haiqiai-publishing
description: 向海奇AI自建发布API上传已确认素材、提交指定账号和浏览器的任务并查询逐项结果。当前交付仅支持模拟执行，不执行真实平台发布。
---

在海奇AI剪藏扩展仓库中使用此技能。当前版本只接受 `executionMode: "simulation"`：模拟草稿不是平台草稿，更不是已发布。需要真实发布时说明当前能力尚未接入，不改用 MultiPost 官方服务或自行操作平台。

先读取仓库中的 [API运行与请求说明](../../packages/publishing-api/README.md) 的“素材与模拟任务”部分。命令从仓库根目录运行，需要 Node 24 及已安装项目依赖。此技能源文件随仓库交付；未自动安装到其他电脑或全局技能目录。

1. 确定本次 API 地址和 Skill 专用密钥文件，用 `HAIQIAI_API_URL`、`HAIQIAI_API_KEY_FILE` 指定。只读取所选服务；不要输出密钥或使用管理密钥代替 Skill 身份。执行电脑必须能访问该地址，远程电脑不能使用发起电脑的 localhost。
2. 通过 `GET /v1/executors`、`/accounts`、`/capabilities` 查询目标。用户指定平台、账号、电脑；浏览器与用户配置可省略，API 在入队时解析并固定默认值。无默认、未知账号或未核对登录时如实说明，不自动换目标。当前账号登记并不代表真实登录状态。
3. 整理各目标最终文字、素材及顺序，向用户展示，取得该内容与目标的执行确认。模拟任务明确写“仅模拟，不对外发布”。开发验收中的合成测试素材可按已有测试授权执行，不能把测试确认记录说成真实发布授权。
4. 用 `pnpm publishing:upload <文件路径> <mediaType> <结果.json>` 上传每份素材。结果必须 `ready: true`；将返回 assetId 填入内容字段，保留原文字和图片顺序。API 素材必须完整上传，不传其他电脑的路径、blob URL、临时外站素材链接或平台 Cookie。
5. 将确认后的请求写入 JSON 文件，调用 `pnpm publishing:admin POST /v1/tasks <请求.json> <结果.json>`。独立配置的 Skill 密钥用于该通用客户端，命令名称不代表需要管理权限。保留结果及旁边的 `.request.json`：超时或结果丢失时原样重跑，复用原幂等键。更改内容或目标须重新确认，并使用新请求及输出路径。
6. 用 `pnpm publishing:admin GET /v1/tasks/<taskId>` 查询到逐个目标的结果，必要时读取分页。明确标出模拟模式、目标浏览器、状态、证据和原因。浏览器约每30秒检查一个任务，也可在工作台点“立即检查模拟任务”。本阶段只核对素材并保存模拟草稿，不验证真实平台账号、限制或发表结果。

错误处理：422 表示整批未入队，展示 fieldErrors，修正文案后重新确认；服务断线保留原请求记录再重试；401 需要用户在管理端更换授权。已领取任务的异常恢复、取消与提交意图由下一阶段实现；当前租约过期会停止并保留记录，不自行建立新任务绕过。遇到失败、需人工处理或未知结果，说明事实、阶段与建议，不以脚本结束或按钮点击宣称发布成功。
